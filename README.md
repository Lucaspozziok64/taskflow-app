# Taskflow-app

## 🧾 Descripción del Proyecto

Aplicación móvil creada con React Native como parte de mi aprendizaje inicial.
Este proyecto marca el comienzo de mi camino en el desarrollo de apps móviles multiplataforma.

---

## 📌 Características actuales

- Creación del proyecto con React Native CLI.

- Renderizado de un mensaje desde un archivo externo hacia App.js.

- Inclusión de estilos utilizando StyleSheet para dar formato al contenido.

---

## 🛠️ Tecnologías utilizadas

### 🛍️ Usuario final
- React Native: framework principal.

- JavaScript (ES6+): lenguaje base.

- StyleSheet: para manejar estilos de manera modular.

---

## 🚀 Cómo ejecutar el proyecto

### 1️⃣ Clonar el repositorio
1. **Clona el repositorio**  
   ```bash
   git clone https://github.com/Lucaspozziok64/taskflow-app.git
   ```

2. **Instala las dependencias**  
   ```bash
   npm install
   ```

3. **Ejecutando con Expo**  
   ```bash
   npx expo start
   ```
